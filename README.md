# Moustache Graphics Gallery

Galería estática para composiciones `.mgt.json` de MGT. Está preparada para
publicarse con GitHub Pages.

Cada tarjeta puede mostrar un MP4 de demostración, copiar el JSON al
portapapeles y descargar el archivo completo para colocarlo en la carpeta
`galeria` de MGT. La galería inicial contiene el efecto Desencriptador Hacker
Matrix.

## Añadir una composición

1. Copia el JSON en `gallery/`.
2. Añade una entrada en `gallery/manifest.json`.
3. Opcionalmente copia el MP4 en `media/` y usa su ruta en `preview`.
4. Publica el repositorio mediante GitHub Pages.

Los JSON incluidos en esta galería se publican bajo CC0 1.0, salvo que una
entrada indique otra licencia. La galería no incluye el motor MGT ni sus
runtimes.
